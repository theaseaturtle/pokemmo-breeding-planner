# Use one active Egg Group and track donor-subtree species

For normally gendered routes, each plan selects one Active Donor Egg Group and every non-Ditto parent in its Donor-Building Subtrees must belong to that group. The planner tracks the real species inherited at every donor node, allows Ditto on either donor side but never Ditto × Ditto, and keeps the Target-Species Mainline separate; this rejects the more flexible per-node Egg Group model in exchange for deterministic compatibility, explainable execution steps, and safer inventory allocation.
