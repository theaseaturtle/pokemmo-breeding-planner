## 如何选择版本

- 想直接使用规划器：使用当前的 [`v1.0.22`](../app/pokemmo-breeding-planner-v1.0.22-2026-08-26.html)。
- 想比较功能如何演变：选择对应 Git 标签，然后查看该标签下的发布文件。
- 想保留某次执行账本：继续使用同一个版本和同一个浏览器配置；不同版本不会共享本地存储。
