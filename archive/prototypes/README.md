# 0.1.0-alpha 原型档案

这个目录保存规划器重建前的原型来源，供追溯早期界面、图鉴数据和交互词汇使用。它们不是当前发布版本，也不应作为可信的执行账本。

- [`pokemmo-breeding-planner-0.1.0-alpha.html`](pokemmo-breeding-planner-0.1.0-alpha.html) 是原始规划器原型。
- [`gemini-source-0.1.0-alpha.html`](gemini-source-0.1.0-alpha.html) 是来自最初生成来源的同代原型快照。

两个文件在功能上是同一 alpha 原型的归档来源；它们都被保留以维持重建过程的可追溯性。当前可用版本位于 [`../../app/`](../../app/)。
